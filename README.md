# Wawo Brand House

Production website source for WAWO Brand House.

## GitHub
Repository: https://github.com/thedanielmalik/wawobrandhouse

## Configure
Edit config.js:
- whatsapp: digits only, international format
- instagramUrl: public Wawo Instagram URL
- beholdFeedId: Behold feed ID for the live, scrollable Instagram widget

## Replace imagery
The current build uses remote image URLs as temporary placeholders. Replace them with approved Wawo/client photography before launch.

## Portfolio
Demo brand names are presentation concepts and should be replaced with verified client work before public claims.

## Deploy
This is a static site and can be deployed on Vercel, GitHub Pages, Netlify or any static host.
